# NPZ

Code for the NPZ models used in Omta et al. (2023) with linear and hyperbolic closures; detailed instructions can be found in Instructions_NPZ.pdf. 

Reference
Omta, A.W., Heiny, E.A., Rajakaruna, H., Talmy, D., & Follows, M.J. (2023). Trophic model closure influences ecosystem response to enrichment. Ecological Modelling, 475, 110183. https://doi.org/10.1016/j.ecolmodel.2022.110183
